# Potential Features

Create one Markdown file per idea in this folder using the naming pattern `YYYY-MM-DD-short-name.md`. Use the template in `template.md` to outline the problem, proposed behavior, and quick acceptance criteria. When the idea is ready to become work:

1. Open a GitHub issue with the feature request template.
2. Move the file into `docs/features/active/<feature-name>/` using the folder template.
3. Link the issue number inside the new folder.
